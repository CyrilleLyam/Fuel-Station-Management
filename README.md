# Fuel Station Management

A management system for fuel stations.

## Tech Stack

**Backend**
- Java 25, Spring Boot 4
- Spring Modulith, Spring Security (OAuth2 Resource Server)
- Spring Data JPA, Liquibase, PostgreSQL
- Casbin (jCasbin) for RBAC
- MapStruct, springdoc-openapi
- Gradle

**Frontend**
- React 19, TypeScript, Vite
- TanStack Router, TanStack Query, TanStack Table
- Axios
- Tailwind CSS 4, Base UI, shadcn
- oxlint
